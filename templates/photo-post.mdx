## Images inline (optional — the main gallery comes from `images[]`)

You rarely need to inline images in the body since the gallery renders them for
you from the frontmatter. But if you ever want to drop a single photo inline
between paragraphs:

**Plain markdown (uncompressed pass-through):**

![A wide shot](./01-wide.jpg)

**Optimized Astro `<Image />`:**

<Image src={import('./01-wide.jpg')} alt="A wide shot" width={1200} />

## Tips

- **Folder name = URL slug.** Lowercase, digits, hyphens.
- **Two-wide masonry** kicks in automatically when `images[]` has 2 or more
  entries. Put them in the order you want them to appear.
- **Each entry can have an `alt`** — always include it for posts that get
  shared around for accessibility reasons.
- If you want a pure gallery post with no prose, just delete everything below
  the closing `---`.
