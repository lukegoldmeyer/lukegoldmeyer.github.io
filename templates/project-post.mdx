## Headings

`h2` and `h3` headings auto-generate a jump-link entry in the right-hand Table
of Contents (desktop) or the inline TOC (mobile). Posts with fewer than 2
headings skip the TOC entirely.

### Sub-headings

`h3` entries are indented in the TOC.

#### h4, h5, h6

Still render but do not appear in the TOC.

## Text formatting

Paragraph text is light-weight Inter in a muted tone, optimized for long-form
reading at ~17px with 1.75 line-height.

Regular text, **bold text**, _italic text_, **_bold italic_**, ~~strikethrough~~,
and `inline code` all render with good contrast. Links are colored and
underlined: [dvdrod.com](https://dvdrod.com) (the design reference for this site)
or an internal link like [the projects page](/projects).

## Code blocks

Inline: `console.log('hello')`.

Fenced code block with a language hint gets Shiki syntax highlighting:

```ts
function greet(name: string): string {
  const timestamp = new Date().toISOString();
  return `[${timestamp}] Hello, ${name}!`;
}

greet('Luke');
```

```python
import numpy as np

def kinetic_energy(mass: float, v: float) -> float:
    return 0.5 * mass * v ** 2
```

```

```

## Images

**Plain markdown** (passes through uncompressed, straight from the folder):

![Alt text describing the image for screen readers](./thumbnail.jpg)

**Astro `<Image />`** (recommended for optimized / resized images):

<Image src={cover} alt="Optimized cover image" width={1200} />

You can also import-and-use any image without a frontmatter declaration:

{/* import extra from './extra-shot.jpg' */}
{/* <Image src={extra} alt="..." /> */}

## Escaping

Backslash-escape any character that would otherwise be interpreted: \*not italic\*,
\`not code\`, \[not a link\](noop).

## MDX components

Because this is MDX rather than plain Markdown, you can import any Astro or
framework component and use it inline. For example:

{/* import Pin from '../../../components/Pin.astro' */}
{/* <Pin pinned={true} /> */}

The current site doesn't ship with many public components, but if one is ever
added (e.g. a callout box, a gallery, an embedded figure) you can drop it in
anywhere in the body and it'll render.

## Tips

- **Folder name = URL slug.** Stick to lowercase, digits, and hyphens.
- **Asset paths are relative to this file.** `./foo.jpg` resolves inside your
  post folder.
- **HMR is fragile around folder renames / deletes.** If something looks wrong
  after reshuffling posts, stop the dev server, delete `.astro/`, and restart.
